
This Weather App is a simple and interactive web application built  with pure HTML, CSS, and JavaScript, The application allows users to search for real-time weather information for any city by entering its name into the search bar when a search is performed the app fetches live weather data from the OpenWeatherMap API and displays key information such as the city name, temperature, weather description, wind speed, and an icon representing the current weather conditions to enhance user experience  The application also updates the date and time  every second using builtin JavaScript functions ensuring that the  information is current the goal of this project was to demonstrate the ability to build a fully functional web application using only core web technologies. The entire experience from DOM manipulation, event handling and API requests and time formatting is implemented using plain JavaScript The layout and design are styled using responsive CSS, making the app visually appealing and easy to use this project purely  front end development skills and  API integration asynchronous JavaScript using async and await clean UI design, user interaction handling, and performancefriendly loading states it also serves as a practical example of how to create a modern and polished application with minimal dependencies while maintaining clarity functionality easy to use.
