
### Weather App

A simple and interactive Weather Application built with HTML, CSS, and JavaScript this application allows users to search for real time weather data for any city displaying the city name, temperature, weather description, wind speed, date, time, and an icon representing the weather. It also includes a smooth fade-in effect, live date/time updates, a loading spinner while fetching data, and inline error messages for empty or invalid input The app is fully built with pure JavaScript.

###  Features
Search Weather

Search for any city by name.

Input validation prevents empty searches.

Inline error messages appear for invalid or empty input.

Weather Display

Shows city name, temperature  weather description, wind speed, and an icon.

Smooth fade-in animation for weather info.

Dynamic live date and time updates.

Loading Indicator

Displays a pure CSS spinner while fetching weather data from the API.

Responsive Design

Works smoothly on mobile, tablet, and desktop.

Clean and modern user interface.

Download or clone the project folder:
